# Система управління фінансовими транзакціями

Консольний додаток на C++ для управління фінансовими транзакціями з можливістю внесення, зняття та переказу коштів між рахунками. Система зберігає історію транзакцій та баланси рахунків.

## Можливості

### Операції з транзакціями

- **Внесення**: Поповнення будь-якого рахунку
- **Зняття**: Зняття коштів з рахунку (з перевіркою балансу)
- **Переказ**: Переказ коштів між рахунками
- **Відстеження балансу**: Оновлення балансів рахунків у реальному часі

### Пошук та відображення

- Перегляд повної історії транзакцій
- Пошук транзакцій за:
  - Типом транзакції (DEPOSIT/WITHDRAW/TRANSFER)
  - Номером рахунку
  - Діапазоном суми

### Збереження даних

- Всі транзакції зберігаються автоматично
- Історія транзакцій зберігається між сеансами
- Баланси рахунків зберігаються

## Початок роботи

### Вимоги

- Компілятор C++11 (g++)
- Термінал/Командний рядок

### Встановлення

1. Клонуйте або завантажте файли проекту
2. Переконайтеся, що всі файли знаходяться в одній директорії:
   - main.cpp
   - Transaction.cpp/.h
   - Command.cpp/.h
   - TransactionManager.cpp/.h
   - Account.h

### Запуск програми

Виконайте скрипт запуску:

```bash
./start.sh
```

Це скомпілює програму та запустить її.
